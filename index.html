For developers

Run it on your own computer with Docker and Git. About two minutes to build on the maintainers' machine.

git clone https://github.com/polysites/polysite.git && cd polysite
git clone https://github.com/polysites/polysite-themes.git themes
git clone https://github.com/polysites/polysite-plugins.git plugins
cp .env.example .env
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
  1. Open http://polysite.localhost/admin.
  2. The setup page asks for your admin account and first site: use the domain examplesite.localhost, pick a theme, tick the starter home page.
  3. Open http://examplesite.localhost. Add examplesite2.localhost with another theme.

Needs ports 80, 443, 3000, 3001 and 5432 free and about 5 GB of disk. This is the hot-reload development setup, not production.
