# polysites.github.io

The landing page of the Polysite GitHub organisation, served at <https://polysites.github.io>.

- `index.html` is the whole page. Edit it here and push; GitHub Pages serves `main`.
- The documentation is **not** in this repository. It is built from the `polysite` repository by its *Docs* workflow and served from the same domain at `/polysite/`
  (project Pages of the `polysite` repository), so this repository holds no copy of it.
- The logo files are copied from `polysite/docs/public`; update them here when the brand files change.
